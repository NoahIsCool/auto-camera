# Bundled fonts

The operator window draws its text in Inter (Regular and SemiBold), built
into the binary by `src/ui/fonts.rs`, so it looks the same on every Mac
and Linux machine. Numbers keep egui's bundled Hack.

| File | Font | Licence |
|---|---|---|
| `Inter-Regular.otf`, `Inter-SemiBold.otf` | [Inter](https://github.com/rsms/inter) 4.0, © 2016-2023 The Inter Project Authors | SIL Open Font License 1.1, [`OFL-Inter.txt`](OFL-Inter.txt) |

The OFL allows the fonts to be bundled and redistributed with software,
including commercial software, as long as they are not sold on their own
and keep this licence.
